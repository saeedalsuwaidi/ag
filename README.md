# AG Holdings WordPress Theme

Source: the v3.0.2 theme supplied in this conversation, with the subsequent Arabic-only founder portrait flip.

## Deployment target

Existing WordPress website: https://ag.ae/
Theme directory: `wp-content/themes/ag-holdings/` (verify the active directory before deploying).

Do not deploy this repository to public_html as a static site or replace WordPress core. The `ag-holdings` directory is an installable theme, not a complete WordPress installation. Database page content and uploaded media are not automatically synchronized by a Git push.

Hostinger auto-deployment is not configured by this commit. Set up deployment for the theme only after confirming the target and taking a backup. The previously observed active theme version was 4.2.0; this source is intentionally based on the owner's selected v3.0.2 package and must not be presented as a copy of that active version.

Installation: upload a ZIP of the ag-holdings folder through WordPress Appearance > Themes. Review Appearance > AG Website Operations after activation. See ag-holdings/INSTALLATION.txt for form delivery, employee access and cache configuration.
